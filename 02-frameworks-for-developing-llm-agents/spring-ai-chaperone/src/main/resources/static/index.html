ℹ About San Francisco Chaperone

What is this?

An AI-powered guide for high school students on a field trip to San Francisco. Ask anything about the itinerary, activities, local weather, or school policies.

How to use it

  • Type your question in the chat box and press Enter (or click ➤).
  • The assistant remembers your conversation — follow-up questions work naturally.
  • Try asking about weather, the schedule, what to pack, or activity options.
  • You can submit feedback about activities — the chaperone will remember it.

When you're done

Click Switch Student in the top-right corner. This clears the current conversation so the next student can start fresh. The session only lasts while the app is running — all history is reset on restart.

💡 Tip: Use Shift + Enter to add a new line in your message without sending it.
